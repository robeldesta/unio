# Unio

An ERP for growing companies, built on Odoo 19 Community: Accounting, People, Payroll, Attendance, Sales, Purchase, Inventory, Production, Projects, Fleet, CRM, Planning, Requests and Me, all posting into one ledger. Sold as SaaS at [unio.et](https://unio.et) and run on-premise for larger clients.

- Start with [CLAUDE.md](CLAUDE.md): layout, how to run it, the rules that matter.
- [docs/conventions.md](docs/conventions.md): product, screen, form, message, payroll and code rules.
- [docs/deploy.md](docs/deploy.md): releases to unio.et and on-premise kits.
- [docs_modules.md](docs_modules.md): every module in one line.

Company-specific code for Eco Green is in `robeldesta/unio_ecogreen`.
